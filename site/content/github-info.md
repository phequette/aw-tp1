## Latest updates

- [pull_request_target blocked by default December 2](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2): starting December 2, 2026, GitHub Actions blocks `pull_request_target` events by default in public repositories unless an Actions event policy explicitly allows them. (GitHub Changelog)
- [New pull request overview page in public preview](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview): aims to show what's blocking a long pull request without scrolling past comments and timeline events. (GitHub Changelog)
- [Build once, run on any agent: A practical guide to agent skills](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/): agent skills capture repeatable engineering work in reviewable, reusable files, while tools and permissions stay specific to the host. (GitHub Blog)
